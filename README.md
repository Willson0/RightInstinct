## О проекте

**Верное чутьё** — это полнофункциональный маркетплейс для собачьего сообщества, реализованный на уровне сервисов формата «Авито».

Платформа позволяет пользователям публиковать объявления о продаже собак, предлагать услуги и товары, размещать мероприятия, а также общаться друг с другом через личные сообщения.  
Проект объединяет удобство Telegram-авторизации и современный WebApp-интерфейс.

---

## Основной функционал

- Авторизация через Telegram
- Публикация объявлений о продаже собак
- Размещение услуг и товаров, связанных с собаками
- Публикация мероприятий
- Личные сообщения между пользователями
- Профили аккаунтов
- Настройка своего профиля
- Современный интерфейс Telegram WebApp
- Адаптивная верстка для мобильных устройств

## Запуск проекта

Проект запускается с помощью Docker.

### Требования
- Docker
- Docker Compose

### Установка и запуск

```bash
docker-compose up --build
```

После запуска приложение будет доступно по адресу, указанному в конфигурации Docker.
